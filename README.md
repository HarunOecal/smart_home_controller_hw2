## Project Description
A simple smart home controller application developed using Flutter and Dart.

## Features
- **Smart Light:** Turn on/off and adjust brightness.
- **Thermostat:** Increase or decrease temperature.
- **Smart Speaker:** Play/pause and adjust volume.
- **Device Counter:** Displays the total number of devices.

## OOP Concepts
- Classes and Objects
- Default and Named Constructors
- Inheritance and Abstraction
- Interface (`Connectable`)
- Mixin (`Schedulable`)
- `static`, `super`, `this` keywords
